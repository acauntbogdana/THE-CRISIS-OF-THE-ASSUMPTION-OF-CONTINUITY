Расшифровка фундаментальных параметров панели приведена в таблице 3.

**Таблица 3. Расшифровка фундаментальных компонентов**

| Имя | Расшифровка | Как считался |
|---|---|---|
| `roa` | Рентабельность активов | NetIncome (Чистая прибыль) / Assets (Активы) |
| `debt_to_equity` | Долг к собственному капиталу | TotalDebt (Общий долг) / Equity (Собственный капитал) |
| `cash_ratio` | Коэффициент денежной ликвидности | Cash (Денежные средства) / LiabilitiesCurrent (Краткосрочные обязательства) |
| `quick_ratio` | Коэффициент быстрой ликвидности | (AssetsCurrent (Оборотные активы) – Inventory (запасы)) / LiabilitiesCurrent |
| `gross_margin` | Валовая маржа | GrossProfit (Валовая прибыль) / Revenue (Доход) |
| `operating_margin` | Операционная маржа | OperatingIncome (Операционная прибыль) / Revenue |
| `net_margin` | Чистая маржа | NetIncome / Revenue |
| `interest_coverage` | Покрытие процентов | OperatingIncome / InterestExpense (Процентные расходы) |
| `asset_turnover` | Оборачиваемость активов | Revenue / Assets |
| `rd_intensity` | Интенсивность НИОКР | RD (Исследования и разработки) / Revenue |
| `sga_intensity` | Интенсивность SG&A | SGA (Комм., общ. и адм. расходы) / Revenue |
| `eps_growth` | Рост прибыли на акцию | TTM (Trailing Twelve Months), г/г |
| `roe` | Рентабельность капитала | NetIncome / Equity |
| `leverage` | Леверидж | Liabilities (Пассивы) / Assets |
| `rev_growth` | Рост выручки | TTM, г/г |
| `ni_growth` | Рост чистой прибыли | TTM, г/г |
| `current_ratio` | Коэф. текущей ликвидности | AssetsCurrent / LiabilitiesCurrent |

*Источники: составлено автором на основе [17–19].*
